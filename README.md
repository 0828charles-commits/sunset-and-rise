# 🌅 Sunset Hunter / 晚霞獵人

Worldwide sunrise & sunset color prediction tool.

全球日出與晚霞預測工具。

## Live Demo

Enable GitHub Pages (Settings → Pages → Deploy from branch `main` / root), then open:

**https://0828charles-commits.github.io/sunset-and-rise/**

## Features

- Dual scores: **sunrise + sunset** (0–100)
- Solar map with correct azimuth (Meeus / SunCalc algorithms)
- Photography tips (English / 繁體中文)
- Open-Meteo weather data (high / mid / low cloud, visibility, humidity)
- Dark sunset-themed UI

## Data sources

- [Open-Meteo](https://open-meteo.com/) forecast API
- Solar position calculated locally in the browser
